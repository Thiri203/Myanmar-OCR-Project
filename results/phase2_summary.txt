# Phase 2 Summary: Myanmar OCR Recognition with PaddleOCR

## Project Goal

This project trains a Myanmar OCR text recognition model using PaddleOCR. The current Phase 2 work focuses on recognition-only OCR, meaning the model takes cropped Myanmar text-line images as input and predicts the corresponding Myanmar text sequence.

This is not a full-page OCR pipeline yet. Text detection and layout analysis are planned as possible future extensions.

---

## Framework and Model

Framework: PaddleOCR  
Task type: Text recognition  
Training style: From scratch  
Dataset: CHN Myanmar OCR dataset  
Model architecture: CRNN + MobileNetV3 + RNN SequenceEncoder + CTCHead  
Loss function: CTCLoss  
Dictionary: Custom Myanmar character dictionary  
Input image shape: 3 x 32 x 100  

PaddleOCR is used as the OCR training framework. The model does not use a pretrained Burmese OCR model. Instead, it learns Myanmar text recognition from the CHN image-label pairs.

## E1 Pilot Result

The E1 Pilot experiment used 5,000 training images and 500 test images for 5 epochs. This experiment confirmed that the complete PaddleOCR training and evaluation pipeline worked successfully on Myanmar text recognition data.

The result was weak, with exact sequence accuracy of 0.0220 and normalized edit distance of 0.2627. This was expected because the pilot used a small subset and short training duration.

---

## E1 Scaled Result

The E1 Scaled experiment increased the dataset to 20,000 training images and 2,000 test images, and trained for 20 epochs. The best checkpoint was saved as `best_accuracy`, with the best result achieved at epoch 16.

The scaled model achieved exact sequence accuracy of 0.2825 and normalized edit distance of 0.5067. This shows a clear improvement over the pilot experiment and confirms that increasing data size and training duration improves Myanmar OCR recognition performance.

---

## Current Limitations

1. The model is recognition-only and does not perform full-page text detection.
2. The model was trained from scratch on a subset of the full CHN dataset.
3. Longer Myanmar text sequences still produce errors.
4. The confidence score is not always equal to correctness, since some incorrect predictions still receive high confidence.
5. Further improvement may require more data, longer training, stronger architecture, better image width handling, or language-aware post-processing.

---

## Next Steps

For the final stage, the project can continue with:

1. Larger CHN training subset, such as 50k or 100k images.
2. External testing on the myOCR dataset.
3. Architecture comparison, such as MobileNetV3 versus ResNet backbone.
4. Ablation study on dataset size, training epochs, or dictionary settings.
5. Possible post-OCR correction for Myanmar text.
